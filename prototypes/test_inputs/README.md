# EvalAI test inputs

These PDFs are optional manual QA inputs. They are not automatically copied into
the demo subject or uploaded by the application. Upload them explicitly when
you want to exercise the document and answer-sheet workflow.

1. `sepm_reference.pdf` — upload as the subject reference document.
2. `sepm_question_paper.pdf` — upload as the question paper.
3. `sepm_student_answer_handwritten_scan.pdf` — select a student and upload as the answer sheet.

The question paper contains section-level marks. The parser should infer Questions 1–2 as 2 marks each and Question 3 as 6 marks.
